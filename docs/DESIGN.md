# Disk Sentinel 设计规范（v0.2）

> 状态：当前产品 UX / UI 权威入口（含信息架构合同）。方法论参照 badminton-lab/DESIGN.md 的合同分层与单一真值原则；对标基准见内部研究 `docs/research/synology-storage-analyzer.md`。

## UX 总纲

1. **按任务组织页面**，不按组件库存组织。用户任务只有三个：①"还剩多少、趋势如何"（判断）②"什么在涨"（定位）③"这目录里是什么"（探索）。低频详情进二级视图，不挤首屏。
2. **结论先行**：每个页面的第一屏先给判断性结论（数字/状态/Top1），证据（图表/表格）随后。
3. **单一真值**：页面职责、信息层级、状态行为只在本文定义；实现与本文冲突时，先改本文再实现。
4. **状态全覆盖**：每个数据区域必须定义空、加载、失败、大量数据四种表现；失败必须给出下一步动作（重试/安装指引），不留白块。
5. 颜色不得单独承担语义，需同时有文字或图标。

## 信息架构（应用壳）

```
┌──────────┬──────────────────────────────────────┐
│ 侧边导航   │  顶栏：当前页标题 + 全局状态徽章 + 主操作  │
│ 64px     ├──────────────────────────────────────┤
│ 🛰 总览    │  页面内容（每页自管滚动）                │
│ 📈 变化    │                                      │
│ 🎯 分布    │                                      │
│ 📦 大文件  │                                      │
│ ⚙ 设置    │                                      │
└──────────┴──────────────────────────────────────┘
```

- 侧边导航固定左侧（桌面 ≥980px）；浏览器独立访问时同样适用（同一前端）
- 移动/窄屏（<980px）：导航折叠为顶栏横向 tab（后续迭代，先标记不支持）

## 页面职责合同

### 总览页（默认落地页）
- **任务**：①判断——还剩多少、比昨天涨跌多少；②一眼 Top 占用
- 内容：状态卡行（剩余/已用/快照数/最近扫描）→ 卷容量趋势 → 今日摘要（最近两次快照的 Top 增长，来自差分）
- 空态：无快照 → 引导"立即扫描"主按钮 + 说明首次扫描 5-15 分钟；仅 1 个快照 → 摘要区显示"明天产生首份对比"
- 主操作：立即扫描（进行中禁用 + 徽章轮询）

### 变化页
- **任务**：任意两天的差分定位
- 内容：快照对选择器（默认 最新 vs 前一）→ 增长/缩减条形图 → 新增/消失目录表 → 历史日报档案列表（reports/*.md，点开回看）
- 同一快照对选择在页面内持久（切换页面保留）

### 分布页
- **任务**：探索"空间在哪"；点开目录查看（用户点名能力）
- 内容：旭日图（当前快照，点击下钻）‖ 目录浏览器（面包屑 + 子目录表：大小/较上快照变化/占比 + Finder 打开 + 该目录趋势抽屉）
- 联动：旭日图点击 → 目录浏览器定位到该目录（QDirStat 双栏联动模式）
- 目录浏览器行操作：点行名下钻；"在 Finder 中打开"按钮调后端 reveal

### 大文件页
- **任务**：找可清理的大目标（近 N 天新增/修改）
- 内容：阈值控件（天数/MB）→ 大文件表（大小/修改时间/路径/Finder）
- 空态文案说明"没有符合条件的大文件修改"而非空白

### 设置页
- 当前为只读信息：监控根、扫描时间、保留策略、数据位置、launchd 状态、卸载指引
- 可写配置（扫描根/时间）列入 Roadmap，避免过早设置项

## 状态约定（全页通用）

| 状态 | 表现 |
|------|------|
| 加载 | 骨架文本"加载中…"，图表容器保留高度不跳动 |
| 失败 | 显示错误消息 + "重试"按钮；后端未启动时提示 main.py install |
| 大量数据 | 表格分页/截断（大文件 topn ≤200；差分 topn ≤100）；路径超长用 title + 截断 |
| 权限受限 | 如实显示 denied_count 与影响说明，不静默 |

## 视觉规范（继承 v0.1 令牌）

```
--bg #f5f6f8 / --card #fff / --border #e4e7ec / --text #1a2233 / --muted #6b7486
--primary #2f6fed（主操作、已用） / --danger #d64545（增长、告警） / --ok #2e9e5b（缩减、剩余）
```

- 字体：系统栈 + PingFang SC；路径等宽（SF Mono 12px，break-all）
- 卡片圆角 12px、图表区无边框卡片；群晖式高密度表格（13px，行 hover 浅灰）
- 剩余 <50GB 或已用 ≥95% → 状态卡数值变 --danger（当前长期告警态）

## 桌面壳（Tauri，apps/desktop/）

- 菜单栏 tray：图标 + 标题显示剩余 GB（由前端定期 invoke 推送）；左键点图标打开主窗口，右键/点开菜单
- tray 菜单：状态行（禁用态，显示剩余与快照数）/ 打开主界面 / 立即扫描（打开窗口并触发前端扫描）/ 退出
- 主窗口关闭 = 隐藏（macOS 菜单栏应用惯例）；退出仅走 tray 菜单
- 壳启动显示本地 loader 页，轮询 FastAPI 可达后跳转 127.0.0.1:7952；不可达时给安装指引
