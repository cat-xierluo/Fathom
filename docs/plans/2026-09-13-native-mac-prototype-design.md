# Fathom 原型第二轮执行方案

用户评审第一轮原型后确认：流程可以，视觉需要明显提升；选择“原生 Mac：克制、精致、轻量”。视觉合同以 [DESIGN 的第二轮约束](../DESIGN.md#原型第二轮原生-mac-视觉方向2026-09-13-用户确认) 为准；本文件仅限定本轮执行。

沿用 ISS-026 和 PR #10，在第一轮独立工程审查结束后安排专属视觉 worker。保持导航、数据状态和核心旅程，主要重做 prototypes/ux/style.css；仅在语义分组和布局必要时调整 index.html/app.js。验证脚本只因合法 DOM 结构变更调整定位，不能删除或弱化状态、溢出、键盘断言。脚本输出改为可指定证据目录，消除绑定某个 worker session 的路径。

优先验证总览和变化→详情在两种窗口的视觉结构，再统一分布、大文件、设置与失败/权限/单快照状态。完成后独立 reviewer 核对真实浏览器与截图，PM 展示同场景前后对照供用户再次评审。未获视觉认可时 ISS-026 保持进行中，不进入 ISS-028 生产实装。

范围外：生产 frontend、真实 API、数据库、安装包、Agent Runtime、深色主题、依赖安装。仅合成数据与本地静态资源，临时服务器和浏览器按 owner 回收。
