状态：**候选，待用户评审**。本文件是 PM 转 `docs/DESIGN.md` 合同提案的底稿；
在用户对照样板评审并确认之前，下列规则**不构成**全站新合同，不约束生产实现。
样板位置：`prototypes/ux/samples.html`（评审壳）→ `sample-current.html`（现状复刻）、
`sample-candidate.html`（候选方案）、`sample-brand.html`（组件与品牌核对）。

- 数据：全部合成，与 ISS-026 原型（`prototypes/ux/app.js`）同一组数值（同一根目录、
  同一快照对、同一 +2.3 GiB 净变化），保证现状与候选同数据对照。
- 现状复刻口径：`frontend/` 审计基线（2026-09-26 实拍，`verify-results/ux-ui-audit-20260926/`），
  逐项复刻审计实测值（h1=17px、导航 11px、卡值 22px、340px 趋势图、180px 页头刻度带、
  一级/设置分区同权重深色块）。它是**反例基线，不是推荐方案**。
- 方案数量：**一套候选**。审计明确"先做可评审样板再统一"，且用户此前已确认 R3 色彩
  体系与 ISS-026 原型的布局方向；本候选是在既有确认范围内收敛，不再另发第二套竞争方案。
  个别点（如"全局扫描按钮样式"）在规则表中注明了备选取舍，供评审时讨论。

## 2. Token 表（候选）

### 字阶（font-size / weight）

| token | 值 | 用途 | 上限约束 |
|---|---|---|---|
| `--fs-display` | 28px / 680 | 主结论数字（tabular-nums） | 每页至多一处 |
| `--fs-h1` | 22px / 640 | 页标题 | 每页一处 |
| `--fs-h2` | 15px / 600 | 区块标题 | 无刻度前缀 |
| `--fs-body` | 14px / 400 | 正文、结论解释 | — |
| `--fs-table` | 13px | 表体、按钮、输入框 | — |
| `--fs-hint` | 12px | 辅助口径、表头（500）、脚注 | 9px 仅品牌位字标 |

路径/数字等宽（tabular-nums 全站，路径 ui-monospace 12px）；禁止全同权重。

### 色板（不变，DEC-023 体系内收敛）

不新增任何颜色。沿用 `--bg #f5f6f8 / --card #fff / --sidebar #eceef2 / --border #e4e7ec /
--hairline #e9ebef / --text #1a2233 / --muted #6b7486 / --trench #345d7f / --mineral #3e7e7c /
--used #244864 / --grow #7c563c / --ok #35716f / --alert #9a4f3b / --warn #7a5c2e / --danger #85453a / --sel #e8edf2`。
候选新增的只是**派生用法**：二级选中底 = rgba(52,93,127,.10)（--primary-weak 同源）。

### 表面 / 间距 / 控件

- 表面 L0/L1/L2/L3 见对照表 #5；阴影只允许 L1 弱阴影与 L3 浮层阴影。
- 间距 token：--sp1 4 / --sp2 8 / --sp3 12 / --sp4 16 / --sp6 24 / --sp8 32；圆角 8（控件）/ 12（表面）。
- 控件高度：输入/选择/次级按钮 32px，主按钮 36px；实心主按钮每视口 ≤1。

### 选中态 / 按钮 / 空态 / 图表

见对照表 #4/#3/#10/#11 与 sample-brand.html「组件与品牌核对」页的可视化实例
（选中态三处并排、按钮族、空态三型、图表规格实例）。

## 3. 品牌呈现（24/26/64px 并排核对结论）

`sample-brand.html` 在同一浅灰底上并列：正式 `assets/icon.png`（128/64px 展示）与
brandBasin SVG 24/26/64px。肉眼可辨的结论（形状一致性以并排实图为据，不靠色值）：

- 正式图标：象牙白 squircle 底板、**非对称**水滴轮廓、四层阶地向午夜蓝中心下陷、顶部刻痕。
- brandBasin 64px：五个共用中心的椭圆 + 三角缺口，呈**同心环**感；层次可辨但轮廓语言不同。
- brandBasin 26/24px：仍可辨色相，但结构退化为近似圆点（已知取舍）。

**本卡的产出是呈现规则，不是替换几何**：

| 位置 | 现状 | 候选 | 说明 |
|---|---|---|---|
| 侧栏字标 | brandBasin 24 + 9px 字标 + 短刻度 | **保留**（主窗口唯一品牌位） | 样板即此形态 |
| 页头锚点 | brandBasin 26 + 180px 刻度带 | **移除** | 与侧栏相邻重复（审计） |
| 关于页 | brandBasin 64 | **保留 64px 位置**；是否换正式位图资产归 ISS-105 | 建议正式产品直接用 `icon.png` 位图或重做矢量（ISS-105 裁决，回写 ISS-088） |
| 菜单栏 tray | brandRing 22pt 灰度 template | 不动 | DEC-023 双形态既有取舍，不在本次议题 |
| 刻度/等深线母题 | 页头带 + h2 前刻度 + 装饰横线 + 结论等深线 | 收敛为三处：侧栏品牌位短刻度、总览结论等深线、二级选中态短刻度 | "少数位置点到为止"（R3 合同原文） |

## 4. 合规自检（两视口）

以下已在扩展后的 `scripts/verify_ux_prototype.cjs` 自动断言（C18–C21）并在 980×640 / 1220×820 实测：

- 首屏任务信息：候选总览 980 下主结论（y=174）与最近变化表首行（y=395）均在首屏内；
  现状复刻同场景 y=676（首屏外，反例复现）。
- 长路径：候选 Top 变化含最长路径行，中间截断 + title 完整，单元格宽 ≤420px，无横向溢出。
- 键盘焦点：表格行 focus 有 inset 焦点环；`:focus-visible` 全局可见（outline 2px）。
- 减少动态：`prefers-reduced-motion` 下等深线动画关闭（含功能性旋转继承原型主体规则）。
- 无横向溢出：两个样板页 × 两视口 + 品牌页两视口全部通过。
