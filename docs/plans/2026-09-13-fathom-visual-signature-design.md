# Fathom 视觉签名第三轮方案

用户已认可第二轮的流程、信息层级、图标和原生 Mac 优雅感，新增目标是让产品拥有可被记住的个人特色。这一轮不再调整信息架构，只在既有可点击原型中验证品牌语言。

评估过三种母题：精密仪器能强化专业感，但容易像系统监控工具；编辑式地图有人文气质，但与磁盘空间的关系较远；“测深/等深线”直接来自 Fathom 的名字，也能自然表达从总量结论下钻到目录证据。因此选择低对比等深线、同心探测纹、短深度刻度与“深度环”作为第三轮视觉签名。

深度环由开放圆环、中心探针和一处刻度缺口组成，沿用现有线条 SVG 语言。它只服务于品牌区、当前目录定位和扫描状态，不能替代五页功能图标。等深线只出现在侧栏品牌区、总览主结论背景和少量选中态，避免把每张卡片装饰成地图。色彩在现有浅色令牌上增加低饱和海沟蓝与矿物青，品牌色不承担成功、警告或错误语义。

动效使用 160–240ms 的轻微探测与层级显现，并完整支持 `prefers-reduced-motion`。禁止写实海浪、船锚、指南针、玻璃霓虹、大面积渐变和营销插画。桌面工具的紧凑、路径可读、数字对齐、键盘焦点和状态语义优先级不变。

实施仅修改 `prototypes/ux/` 和必要的原型验证脚本，继续使用合成数据。验收保留已有 99 项浏览器门禁，并增加品牌元素稀疏度、语义色不混用、减少动态偏好，以及 980×640、1220×820、1440×900 同场景前后截图。worker 交付后由独立 reviewer 固定 head 验收，PM 更新 PR #10 和预览，再交用户决定 ISS-026 是否完成。
